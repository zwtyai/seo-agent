# 每日冷知识

栏目定位：**让人想转述的反直觉事实**——可核对，有画面，读完想跟人说一句。  
不讲课，不写长证明，不推荐产品。读完要有「卧槽原来是这样」——脑子里的画面被改写一截。

## 质量门槛（谈资 > 落差 > 场景）

先过这三关，过不了就换：

1. **谈资测试**：朋友吃饭时，你会不会主动说出来？说完对方会不会接话？
2. **画面改写**：大家脑子里有一幅默认图 A；事实把图改成 B（方向、结构、归属、因果）。
3. **可核对**：百科、博物馆、论文、正规媒体、权威机构有原文页。

只有「其实没那么有用 / 不等于最佳 / 不会真的坏」——没有新画面——一律不要。那是轻量辟谣，不是冷知识。

### 强选题（要这种）

- 闪电看起来从上往下劈，其实回击往往是从地面往上冲（画面方向反了）
- 静脉看起来蓝，血其实一直是红的（看到的颜色是错觉）
- 香蕉在植物学里算浆果，草莓反而不算（分类归属翻了）
- 加盐并不能让水明显更快烧开（厨房里人人信、但机制打脸）

### 弱选题（不要这种）

- 坐得笔直，不等于最佳坐姿 → 生活小建议，没有画面
- 暗光下读书，不会「看坏」眼睛 → 轻量辟谣，早刷过、没谈资
- 试香时闻咖啡豆，并不能「重置」嗅觉 → 小众场景 + 只否定妙招
- 洗衣机要定期清洗 / 冰箱温度要调对 → 说明书提醒

优先找：**方向反了 / 看到的是错觉 / 归属翻了 / 因果搞反了 / 尺度离谱但可核对**。  
少找：**不等于最佳、不会真坏、并不能重置、其实也行、其实差不多**。

## 场景：优先有画面的世界，少挤生活小妙招

轮换这些面（前面优先）：

- 天气、雷电、天空与自然现象
- 材料与物理小现象（铝箔、水、火、金属、光）
- 感官与错觉（颜色、冷热、味道、平衡）
- 动植物与自然观察（分类、习性——非灵异、非疗效）
- 人体结构常见误解（看得见的错觉，非治病）
- 城市出行与通勤里的物理/距离错觉
- 数字与尺度直觉（找零、百分比、大小——非投资）
- 穿衣鞋帽与体感里的物理（非穿搭清单）
- 饮水、口渴与冷热饮（非疗效）
- 时间节奏与拖延错觉
- 运动、拉伸与热身误区（非训练计划）
- 购物包装与消费习惯（非理财）
- 宠物、草木养护常识（非偏方）
- 家用小物用法（要有机制反差，不要说明书）
- 厨房与食物、清洁洗衣、睡眠疲劳——可以讲，但必须有机制打脸；别连周霸榜，也别落成「记住这样做」

刻意少碰：坐姿办公小建议、暗光用眼辟谣、香水咖啡豆类小妙招——这类几乎没有谈资。

## 口气

- 短，像跟朋友说一件刚刚核对过的事
- 好奇，允许轻轻一惊，但别吓人、别喊「震惊」
- 句子干净。不用「在当今」「综上所述」「赋能」

## 一张卡片

1. 标题：点出误判或反差。最好能让人脑子里闪出画面。不要「万亿倍」「震惊」「竟然」「你绝对不知道」
2. 事实：两三句，先点破常见想法，再说核对过的事实；尽量写出「看起来怎样 → 其实怎样」
3. 带走一句：下次怎么看、别再信什么。要具体，不要「颠覆了固有印象」
4. 来源：站点名和可打开的原文链接（百科、博物馆、论文、正规媒体、权威机构）。不要用搜索跳转短链

## 发之前问自己

- 你会不会转述给旁边的人？不会就换
- 有没有改写脑子里的画面？没有就换
- 是不是又在讲「不等于最佳 / 不会真坏 / 并不能重置」？是就换
- 是不是又在讲冰箱/洗衣/睡觉的常规提醒？是就换
- 来源能不能点开核对？不能就别发
- 是不是网上已经刷烂的梗？刷烂了就换

## 明确不做

- 治病、疗效、补剂、恐吓式健康内容
- 投资理财建议、荐股
- 法律结论、道德审判
- 心理学疗愈鸡汤、性格测试、两性对立
- 思想实验空谈、灵异、政治争议
- 据说、网传、听说、据传
- 震惊、绝了、万亿倍、你绝对不知道、刷屏、秒懂
- 「完全颠覆」「简直颠覆了我们的固有印象」这类空句
- 纯保养清单、步骤长文、评分、产品试用
- 轻量生活辟谣：不等于最佳坐姿、暗光不会看坏眼、闻咖啡豆不能重置嗅觉
- 简报里没有的数字和人物

## 小红书版（另存一份，不自动发帖）

同一条事实再写成笔记文案，方便复制到小红书：

1. 封面大字：≤18 字，点出误判，不吓人；最好有画面钩子
2. 封面副行：一句钩子，引出带走一句
3. 笔记标题：可搜索，像正常人说话
4. 正文：短段 + 空行；先钩子，再事实，再带走一句；不要外链
5. 标签：固定栏目标签 + 本条场景词
6. 来源备注：只写站点名，例如「来源：维基百科」，不要贴长 URL

口气比站内卡片更口语一点，但仍要可核对，不编数字。
