# 每日冷知识

这个栏目把网上散落的一条事实收成固定格式。不讲课，不写长证明，不推荐产品。
读完要带走一个小判断，不能只剩「哇，好意外」。

## 口气

- 短，像跟朋友说一件刚刚核对过的事
- 好奇，但别吓人
- 句子干净。不用「在当今」「综上所述」「赋能」

## 一张卡片

1. 标题：一句话，说清事实。不要「万亿倍」「震惊」「竟然」
2. 事实：两三句，用自己的话
3. 带走一句：下次可以怎么看、别再信什么、和日常哪个判断有关。不要只写「颠覆了固有印象」
4. 来源：站点名和可打开的原文链接（百科、博物馆、论文、正规媒体）。不要用搜索跳转短链

## 发之前问自己

- 这条改不改变读者某个小判断？改不了就换
- 来源能不能点开核对？不能就别发
- 是不是网上已经刷烂的梗？刷烂了就换

## 小红书版（另存一份，不自动发帖）

同一条事实再写成笔记文案，方便复制到小红书：

1. 封面大字：≤18 字，说清事实，不吓人
2. 封面副行：一句钩子，引出带走一句
3. 笔记标题：可搜索，像正常人说话
4. 正文：短段 + 空行；先钩子，再事实，再带走一句；不要外链
5. 标签：固定栏目标签 + 本条相关词
6. 来源备注：只写站点名，例如「来源：维基百科」，不要贴长 URL

口气比站内卡片更口语一点，但仍要可核对，不编数字。

## 不要写

- 据说、网传、听说、据传
- 震惊、绝了、万亿倍、你绝对不知道、刷屏、秒懂
- 「完全颠覆」「简直颠覆了我们的固有印象」这类空句
- 搜索量、关键词、竞品
- 步骤清单、评分、产品试用
- 简报里没有的数字和人物
