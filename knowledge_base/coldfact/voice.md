# 每日冷知识

栏目定位：**反直觉、但可核对的日常误判**。  
不讲课，不写长证明，不推荐产品。读完要有「哦，原来如此」——改掉一个想当然的判断。

## 质量门槛（比场景更重要）

先问有没有**认知落差**：

1. 很多人默认相信 A
2. 可核对的事实是 B
3. 读者会说「原来不是那样」或「下次我会改看法」

没有落差的条目不要发。例如「洗衣机要定期清洗」「冰箱温度要调对」——这是说明书提醒，不是冷知识。

优先找：**以为有用其实没用 / 以为有害其实无妨 / 以为看得到其实是错觉 / 以为越大越好其实过犹不及**。

## 场景（轮换，别挤在家务）

可以讲，但同一周不要堆满：

1. 厨房与食物（非养生偏方）——易滥，慎用
2. 清洁与洗衣收纳——易滥，慎用
3. 睡眠与疲劳误解——易滥，慎用
4. 家用小物与材料（铝箔、砧板、塑料、金属、纸）
5. 人体感受与感官错觉（味觉、颜色、冷热、平衡）
6. 天气、空气与体感（静电、闷热、下雨、防晒以外的体感误区）
7. 城市出行与空间（排队、电梯、左右通行、距离错觉）
8. 数字屏幕与注意力习惯（非心理健康鸡汤）
9. 动植物与自然观察（非灵异、非疗效）
10. 声音、气味与错觉

## 口气

- 短，像跟朋友说一件刚刚核对过的事
- 好奇，允许轻轻一惊，但别吓人、别喊「震惊」
- 句子干净。不用「在当今」「综上所述」「赋能」

## 一张卡片

1. 标题：点出误判或反差。不要「万亿倍」「震惊」「竟然」「你绝对不知道」
2. 事实：两三句，先点破常见想法，再说核对过的事实
3. 带走一句：下次怎么看、别再信什么。要具体，不要「颠覆了固有印象」
4. 来源：站点名和可打开的原文链接（百科、博物馆、论文、正规媒体、权威机构）。不要用搜索跳转短链

## 发之前问自己

- 读者会不会「哦」一下？不会就换
- 是不是又在讲冰箱/洗衣/睡觉的常规提醒？是就换角度
- 来源能不能点开核对？不能就别发
- 是不是网上已经刷烂的梗？刷烂了就换

## 明确不做

- 治病、疗效、补剂、恐吓式健康内容
- 投资理财建议、荐股
- 法律结论、道德审判
- 心理学疗愈鸡汤、性格测试、两性对立
- 思想实验空谈、灵异、政治争议
- 据说、网传、听说、据传
- 震惊、绝了、万亿倍、你绝对不知道、刷屏、秒懂
- 「完全颠覆」「简直颠覆了我们的固有印象」这类空句
- 纯保养清单、步骤长文、评分、产品试用
- 简报里没有的数字和人物

## 小红书版（另存一份，不自动发帖）

同一条事实再写成笔记文案，方便复制到小红书：

1. 封面大字：≤18 字，点出误判，不吓人
2. 封面副行：一句钩子，引出带走一句
3. 笔记标题：可搜索，像正常人说话
4. 正文：短段 + 空行；先钩子，再事实，再带走一句；不要外链
5. 标签：固定栏目标签 + 本条场景词
6. 来源备注：只写站点名，例如「来源：维基百科」，不要贴长 URL

口气比站内卡片更口语一点，但仍要可核对，不编数字。
