# 每日冷知识

栏目定位：**纠正日常生活里的小误判**。  
不讲课，不写长证明，不推荐产品。读完要带走一个明天用得上的小判断。

## 做什么

优先这些场景：

1. 厨房与食物（非养生偏方）
2. 清洁与洗衣收纳
3. 睡眠与疲劳的常见误解
4. 家用小物的正确用法
5. 人体感受里「课本/传说是错的」那一类（配菜，不要占满）

选题先问：读者下次做饭、洗衣、睡觉或用东西时，会不会改一个小判断？

## 口气

- 短，像跟朋友说一件刚刚核对过的事
- 好奇，但别吓人
- 句子干净。不用「在当今」「综上所述」「赋能」

## 一张卡片

1. 标题：一句话，说清误判或事实。不要「万亿倍」「震惊」「竟然」
2. 事实：两三句，用自己的话
3. 带走一句：下次可以怎么做、别再信什么。不要只写「颠覆了固有印象」
4. 来源：站点名和可打开的原文链接（百科、博物馆、论文、正规媒体、权威机构）。不要用搜索跳转短链

## 发之前问自己

- 这条改不改变一个日常小判断？改不了就换
- 来源能不能点开核对？不能就别发
- 是不是网上已经刷烂的梗？刷烂了就换

## 明确不做

- 治病、疗效、补剂、恐吓式健康内容
- 投资理财建议、荐股
- 法律结论、道德审判
- 心理学疗愈鸡汤、性格测试、两性对立
- 思想实验空谈、灵异、政治争议
- 据说、网传、听说、据传
- 震惊、绝了、万亿倍、你绝对不知道、刷屏、秒懂
- 「完全颠覆」「简直颠覆了我们的固有印象」这类空句
- 步骤长文、评分、产品试用
- 简报里没有的数字和人物

## 小红书版（另存一份，不自动发帖）

同一条事实再写成笔记文案，方便复制到小红书：

1. 封面大字：≤18 字，点出误判，不吓人
2. 封面副行：一句钩子，引出带走一句
3. 笔记标题：可搜索，像正常人说话
4. 正文：短段 + 空行；先钩子，再事实，再带走一句；不要外链
5. 标签：固定栏目标签 + 本条场景词（如厨房、睡眠）
6. 来源备注：只写站点名，例如「来源：维基百科」，不要贴长 URL

口气比站内卡片更口语一点，但仍要可核对，不编数字。
