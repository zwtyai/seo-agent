# 第 072 期 · 你以为藏起来就整洁了？不透明收纳盒可能让家更乱
很多人喜欢用不透明的收纳盒把杂物「藏」起来，觉得眼不见为净，家里就整洁了。但奇怪的是，这种做法反而可能让你忘了盒子里有什么，结果就是重复购买，或者东西闲置到最后越堆越多，让家变得更乱，而不是更整洁。

带走一句：下次整理时，别再以为藏起来就万事大吉，看不见的物品更容易被遗忘和重复购买。
