# 第 087 期 · 你以为舌头尝出味道？其实是眼睛在「调味」
我们总以为舌头是品尝味道的唯一法官，但实际上，眼睛才是餐桌上的第一位评委。研究发现，当把樱桃味饮料染成橙色，人们会觉得它是橙子味；染成绿色，又成了青柠味。我们的视觉会在味蕾之前，悄悄地预设了味道的期待，甚至能改变你对真实风味的判断。

带走一句：下次品尝食物时，别只相信舌头，也要留意颜色可能带来的“味觉错觉”。
