# 第 086 期 · 镜子没颠倒左右，是你的大脑在「变戏法」
很多人以为镜子会把左右颠倒，但却不会颠倒上下。可实际上，镜子既不会特意颠倒左右，也不会颠倒上下。它唯一做的，是把你面向镜子的「前后」方向进行反转。我们之所以会觉得镜中的自己左右反了，是因为我们的大脑习惯性地将镜中影像理解为另一个人转过身来面对我们，从而产生了左右颠倒的错觉。

带走一句：下次照镜子时，别再以为镜子有“左右不分”的超能力。记住，镜子只是忠实地把你的“前后”翻转了，是你自己的大脑在玩“左右颠倒”的游戏。
