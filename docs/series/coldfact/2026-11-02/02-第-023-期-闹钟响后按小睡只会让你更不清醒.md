# 第 023 期 · 闹钟响后按“小睡”，只会让你更不清醒

早上闹钟响了习惯按个“小睡”，想多赖床几分钟？其实这并不能让你更清醒。身体在每次短暂的“回笼觉”中，都可能重新进入睡眠周期，但很快又被叫醒，这样反而会打乱正常的睡眠节律，让你醒来后更疲惫、更迷糊，也就是加重了那种刚睡醒时的昏沉感。

带走一句：别再指望那几分钟的“回笼觉”能帮你补回精神了。为了早上能清醒利落地开始一天，下次闹钟响了，尽量直接起床吧。
