# 第 020 期 · 喝咖啡会脱水？其实它也能帮你补水

很多人都以为咖啡因利尿，所以喝咖啡会导致身体脱水。但研究发现，如果你是经常喝咖啡的人，每天喝三到四杯并不会让你脱水。咖啡里的大部分水分，身体都能有效吸收，甚至可以算进你每天的总饮水量。

带走一句：下次喝咖啡时，不必再担心它会让你越喝越渴。它也能为身体补充水分，但白开水仍是最佳选择。
