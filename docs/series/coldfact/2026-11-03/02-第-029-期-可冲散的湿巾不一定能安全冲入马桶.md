# 第 029 期 · “可冲散”的湿巾，不一定能安全冲入马桶

很多人都觉得，包装上写着“可冲散”或“可冲入马桶”的湿巾，用完就能像厕纸一样直接冲走。但其实，这类湿巾分解的速度远不如厕纸，它们在排水管道里很容易缠绕成团，不仅会堵塞家里的管道，还会给市政污水处理系统带来麻烦。

带走一句：下次再看到声称“可冲散”的湿巾，别轻易相信它能安全消失在马桶里。为了避免堵塞，除了排泄物和卫生纸，其他都扔垃圾桶。
