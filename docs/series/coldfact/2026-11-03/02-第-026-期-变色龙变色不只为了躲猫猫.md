# 第 026 期 · 变色龙变色，不只为了躲猫猫

很多人觉得，变色龙改变体色，就是为了融入环境、躲避天敌，或者悄悄接近猎物。但其实，伪装只是它们变色的原因之一。变色龙更多时候是通过皮肤中特殊的纳米晶体层，快速反射不同波长的光线，来表达兴奋、恐惧、求偶等情绪，调节自身体温，以及和其他同类交流“信息”。

带走一句：下次再看到变色龙变色，别只觉得它在玩“捉迷藏”，它可能正在“说话”或者“调温”。
