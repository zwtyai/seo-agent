# 第 041 期 · 血管看起来是蓝的，但血一直是红的

很多人看到手腕上凸起的「青筋」是蓝色的，会以为血管里流淌着蓝色的血液。但其实，无论在动脉还是静脉中，人体的血液始终是红色的，只是含氧量不同导致颜色深浅有别。我们之所以看到静脉呈现蓝色或青色，是因为光线穿透皮肤时产生了视觉错觉：红光能穿透皮肤更深层并被血液吸收，而蓝光大部分在皮肤浅层就被散射和反射回来，进入我们的眼睛。

带走一句：下次再看到手上的「青筋」，别再以为里面流的是蓝色的血了，那只是光线在皮肤下开的「玩笑」。
